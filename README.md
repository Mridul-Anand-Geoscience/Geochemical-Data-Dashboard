# Geochemical-Data-Dashboard
Python web application for exploratory data analysis and visualization of multi-element geochemical datasets

## Project Overview
This project is an interactive data visualization tool built with Python and Streamlit. It is designed to process and analyze geological and geochemical datasets, allowing users to rapidly identify trends, anomalies, and correlations in trace element distributions (such as cobalt, nickel, and iron).

## Features
* **Automated Data Processing:** Instantly reads and cleans standard `.csv` assay data.
* **Exploratory Data Analysis (EDA):** Generates dynamic correlation matrices and scatter plots.
* **Interactive UI:** Allows users to filter and select specific elemental variables on the fly without writing code.

## Tech Stack
* Python
* Pandas (Data manipulation)
* Streamlit (Web deployment)
* Plotly / Seaborn (Visualization)
